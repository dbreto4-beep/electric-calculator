Fórmulas utilizadas

Monofásico: ΔV = 2 · L · P / (γ · S · V)  ·  I = P / (V · cos φ)

Trifásico: ΔV = L · P / (γ · S · V)  ·  I = P / (√3 · V · cos φ)

L = longitud (m), P = potencia (W), γ = conductividad (m/Ω·mm²), S = sección (mm²), V = tensión (V). Límites de caída de tensión: 3 % para alumbrado y 5 % para otros usos (REBT ITC-BT-19). No se considera la reactancia del cable.
